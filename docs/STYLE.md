# 文档书写规范

本仓库所有 Markdown 遵循本规范。规范可被 `scripts/checkregister.py` 机器校验，未通过则 CI 失败。

---

## 1. 基本原则

| 原则 | 要求 |
|---|---|
| 定义优先 | 每个文档首段回答：这是什么、输入什么、输出什么 |
| 陈述句 | 描述事实与规则，不使用祈使、感叹、反问 |
| 可核对 | 数值、路径、命令、退出码必须与实际一致；无法核对的表述删除 |
| 术语统一 | 同一概念全文同一名称，见第 4 节术语表 |
| 无修辞 | 不使用比喻、拟人、口号、程度副词堆叠 |

---

## 2. 禁止项

| 类别 | 禁止示例 | 替代写法 |
|---|---|---|
| 祈使 | 形容词使用限制、不使用第五档字号 | 形容词限用规则见 §9；字号限定四档 |
| 口号 | 概述：先定结构，再做图 | 执行顺序：先确定结构，再制作页面 |
| 比喻 | 一叠各自为政的图 | 多张独立页面，缺少统一调色与连续背景 |
| 拟人 | 齿轮不说谎 | 镂空盘面可见齿轮与摆轮 |
| 主观程度 | 无判定值的程度表述 | 替换为可测值，如：文字宽度超过 480 px |
| 口语连接 | 、、、完成 | 删除，或改为"因此""据此" |
| 第一人称叙事 | 我们已知问题 | 已知问题（见 `pitfalls.md`） |
| 标题拟人/疑问 | 为什么做这个味道 | 香型设定依据 |

---

## 3. 结构要求

```
# 标题（名词短语）
一句话定义（陈述句，含输入与输出）

## 章节（名词短语，不带标点）

条目统一用表格或「条件 → 处理」两栏，不用散句罗列。
每条规则给出可判定的标准（数值、命令、文件名）。
```

---

## 4. 术语表

| 术语 | 定义 |
|---|---|
| 页面类型 | HERO / FEATURE / SPEC / GRID / BRAND 五类，单页仅使用一类 |
| 字号档 | T1 / T2 / T3 / T4 四档，像素区间见 `layout-specs.md` |
| 统一收口 | 调色 → 透明化 → 连续背景 → 长图 → 切回单页 的完整链路 |
| 连续背景 | 覆盖全部页面高度的单张背景图，页间以固定间距衔接 |
| 基准（reference） | 已交付成品的副本，用于复现验收比对 |
| 复现验收 | 重新生成后与基准逐页比对高度与像素差 |
| 禁用词 | 无依据的形容词、大词、促销话术、无凭证的权威表述、编造数据 |
| 素材生成 | 通过图像模型产出原始素材的阶段，与排版阶段分离 |

---

## 5. 数值与单位

```
尺寸        宽×高，单位 px，写作 1200×25438
容差        写作 ≤ 6/255
百分比      写作 22%
文件大小    KB / MB，保留一位小数
时间        日期写 YYYY-MM-DD；时长写"分钟""小时"
命令        置于代码块，可直接执行，不自造缩写
```

---

## 6. 文件与路径

```
路径用反引号包裹：`scripts/reproduce.py`
仓库内路径用相对形式：`examples/watch/reference/`
本机绝对路径不出现在文档中（除环境变量示例）
```

---

## 7. 校验

```bash
python scripts/checkregister.py .        # 规范校验，命中即退出码 1
```

校验内容：第 2 节禁止项的词汇命中、标题是否为疑问/祈使句式、数值格式（px、容差、百分比）。
