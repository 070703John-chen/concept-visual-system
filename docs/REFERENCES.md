# 参考来源与借用边界

本文件记录设计决策所依据的外部参考、借用范围与未借用内容。
目的有二：一是可追溯，二是明确哪些是他人的成果、哪些是本项目的产出。

---

## 1. 三条边界

| 边界 | 规则 |
|---|---|
| 不复制图像 | 他人作品中的图像、插画、产品图一律不进入本仓库，也不进入成品 |
| 只借用语法 | 可借用的是结构关系（标签行位置、章节标题层级、数据条目形式、双语文案排布） |
| 记录来源 | 每一项借鉴在案例文档中指向本文件的条目编号，不写"参考了某些作品" |

配色数值、字号、栅格、文案均为本项目自行确定，不取自参考作品。

## 3. 记录缺口

R-01 的完整链接未在查阅时保存，仅有案例标识片段。补录方式：

1. 在站酷检索作者名「大嘴是个设计师」或作品名「松也香氛」；
2. 取得作品地址后填入上表「链接」列；
3. 若作品已下架，保留作者名与查阅日期，并在备注中标注「已下架」。

未补录前，该条目按「来源可识别、地址待补」处理，不作为可引用链接使用。

## 4. 如需引用图像

| 场景 | 做法 |
|---|---|
| 内部比较 | 可截图比对，截图不进入仓库、不进入成品 |
| 对外展示 | 取得作者授权，或在展示中明确标注出处与链接 |
| 作品集说明 | 只描述借用的语法，不呈现他人图像 |

本项目的两个案例未使用任何外部图像：产品图由商业图像服务生成，品牌为虚构。
