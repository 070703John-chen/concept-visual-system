# 案例二：南枝 NÁNZHÍ（亮调香水，11 页）

结构化记录：背景 → 决策 → 结果 → 结论。与案例一互补：本例为高调素材，且起点是一套旧电商页面。

---

## 一、背景

| 项 | 内容 |
|---|---|
| 性质 | 自命题概念项目，虚构品牌 |
| 起点 | 已有 13 页旧电商页面（含虚构价格 ¥398、促销勾选标签、"留香 8 小时"式表述） |
| 目标 | 改造为品牌手册，输出 11 页 + 连续长图 1200×17800 |
| 素材 | 旧页面中的产品图 + 新增生成素材（41 张，含 4 张去背用纯白背景素材） |
| 约束 | 旧页面图像内含价格与促销文字，不可直接沿用；生成素材的瓶型与旧图不一致 |

问题定义：旧页面承载的是促销语境（价格、勾选标签、功效承诺），与品牌手册的陈述语境冲突。
素材不足以支撑 11 页，需先解决"同一支瓶"的复用问题。

---

## 二、决策

### D1 保持高调，改以信息密度建立统一性

| 项 | 内容 |
|---|---|
| 决策 | 不使用案例一的低调参数，保留原素材的高调属性 |
| 依据 | 实测降低明度后，白色织物转为污浊灰、背景偏灰蓝，材质感下降 |
| 替代手段 | 统一背景 + 统一版式 + 固定字号级 |
| 工具 | Pillow（画布）、numpy（米色渐变与颗粒） |

### D2 去背建立可复用素材（技术支点）

| 项 | 内容 |
|---|---|
| 决策 | 从纯白背景素材提取瓶体，输出 521×967 RGBA，边缘羽化 1.2 px |
| 依据 | 素材不足时，单一瓶体可在任意背景复用，替代多张场景图 |
| 实现 | 阈值 > 238 + 自边缘 BFS 漫水 + alpha 模糊 |
| 限制 | 深色背景上出现细白边，故背景限定为中浅调 |
| 工具 | Pillow（`ImageDraw.floodfill` 等价实现、`ImageFilter.GaussianBlur`）、numpy |

### D3 旧页面只取素材或文本，版式全部重做

| 项 | 内容 |
|---|---|
| 决策 | 旧页仅供图像或文案来源，版式（纯白背景、价格、勾选标签）一律不复用 |
| 依据 | 版式承载语境；沿用版式即沿用促销语境 |
| 裁切约束 | 裁切框须避开旧价格与促销文字 |
| 工具 | Pillow（裁切与合成）；规则见 `reference/pitfalls.md` 第 14 条 |

### D4 采用信息密集型版式语法

| 项 | 内容 |
|---|---|
| 决策 | 采用五类结构：顶部四点标签、章节标题 + 英文对照、○ 数据条目、中英双语段、关键词页 |
| 依据 | 高调且低对比的画面需要更多结构元素承载信息，否则单页显空 |
| 工具 | Pillow（文本渲染与对齐）、`textlength` 计算文本宽度 |

### D5 双香型：同瓶型、改色、重绘标签

| 项 | 内容 |
|---|---|
| 决策 | 第二款（冷调 002）不重新生成，改为主图瓶体去饱和 + 瓶身冷处理 + 标签重绘 |
| 依据 | 重新生成会改变瓶型，破坏"同一产品线"的前提 |
| 标签重绘 | 先测量标签区域（x 0.238–0.792、y 0.370–0.742），再覆盖绘制 |
| 工具 | Pillow（通道混合、区域覆盖） |

### D6 长图羽化合成

| 项 | 内容 |
|---|---|
| 决策 | 每页上下羽化 90 px 贴入连续米色背景，页间隙 20 px；排除"附原版封面"页 |
| 依据 | 页面为不透明成品，直接拼接会产生硬边 |
| 工具 | `examples/nanzhi/scripts/build_long.py` |

### D7 文案去除促销语汇

| 项 | 内容 |
|---|---|
| 决策 | 删除价格、勾选标签、"留香 8 小时"式承诺，改为香调构成与使用条件 |
| 依据 | 无凭证的功效承诺属禁用项；价格不属品牌手册内容 |
| 工具 | `scripts/checkcopy.py`、`templates/forbidden-claims.txt` |

---

## 三、结果

| 指标 | 数值 |
|---|---|
| 页面数量 | 11（第 12 页"附原版封面"仅作单页展示，不进长图） |
| 长图尺寸 | 1200×17800；网页版 760×11273 |
| 去背素材 | 521×967，边缘羽化 1.2 px |
| 复现精度 | 高度全部一致；平均像素差 0.15–0.81（容差 6/255） |
| 校验 | `checkcopy` 0 命中；`reproduce --case nanzhi` → PASS |

未达成项：第二款香型的真实瓶体（为改色与重绘，非独立产品图）。

---

## 四、结论

**可迁移的条件**

1. 素材为高调（纯白或浅色背景）时，优先走本例路径；低调参数会降低材质表现。
2. 存在至少一张纯白背景素材，可完成去背并复用。
3. 旧页面可裁切出干净素材区域（避开价格与促销文字）。

**方法层结论**

1. 高调项目的统一性由**背景与版式**提供，不由调色参数提供；案例一的 D1/D4 在此不适用。
2. 素材不足时，去背复用的收益高于继续生成新素材：前者保证产品一致性，后者引入瓶型漂移。
3. 旧页面改造的边界是"取素材与文本，不取版式"；版式决定语境，沿用版式即沿用旧语境。

**成本对照**

| 环节 | 耗时占比 |
|---|---|
| 去背与素材整理 | 约 20% |
| 版式与文案 | 约 50% |
| 长图合成与校验 | 约 30% |

数据来源：本案例的实际执行记录；比例为估计值，非精确计时。
