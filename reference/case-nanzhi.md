# 案例二：南枝 NÁNZHÍ（亮调香水，11 页）

> 与手表案例互补：手表是**暗调、强结构**；南枝是**亮调、弱结构、信息密集**。
> 更重要的是：南枝是从一套"旧电商页面"改造出来的，能说明"救旧图"怎么做。

---

## 一、起点：一套不能直接用的旧页面

接手时有 13 页（2026-11-10 版），问题不在画质，在**话语体系**：

```
标题      "空山新雨后"           诗句，有意境，无信息
标签      ✔木质调 ✔留香8小时 ✔中性香   电商促销语汇
价格      ¥398 印在图上（3 页）   作品集不该出现，且是虚构价
底子      一半页面是白底           翻起来像淘宝详情页
字号      六档混排               没有系统
```

**判断：这不是"改文案"能救的，是整套视觉语言要换。**

---

## 二、关键决定：不压暗，改信息密度

第一反应是"把手表那套暗调搬过来"。试过，失败：

```
压暗一档   白衬衫变脏灰，像手机拍的
压暗+冷处理 背景发灰蓝，廉价感更重
```

**原因：素材是高调的（白衬衫 + 暖白背景），信息全在亮部；压暗等于把信息压掉。**

**改判：保留亮调，靠"结构"取胜。**亮调不等于廉价 —— Byredo、Diptyque 都是白底。

---

## 三、抄参考：站酷香水品牌全案的语法

在站酷找到《松也香氛品牌设计》，抄了五条：

```
① 顶部四点小标签    ◆ 品牌 ◆ 品类 ◆ 年份 ◆ slogan
② 章节标题带英文    ● 香调分析                    NOTES ANALYSIS
③ ○ 数据条目        ○ 前调 30%  ○ 中调 45% …
④ 中文段 + 英文小字  同一句话给两种语言
⑤ 关键词页          木质 × 苔藓 × 雨后（大字 + 中英对照 + 模糊实拍背景）
```

**这五条构成了"信息密集但不乱"的骨架。**

---

## 四、突破口：白底抠瓶

```
手里只有 4 张原图 → 撑不起 11 页
但有一张白底主图 → 抠出瓶子 → 从此"同一支瓶"可以放在任意背景上
```

**这是整个改造的技术支点：**

```
抠瓶（521×967，边缘羽化 1.2px）
  ↓
配代码生成的单色渐变背景（奶油 / 琥珀 / 灰蓝）
  ↓
瓶子永远同一支，背景可随时换色
```

**代价与限制**：抠图边缘在深色底上会露出细白边，所以背景只能用中浅调。

---

## 五、旧图新装（把旧页面救成新页面）

旧页面不是全部丢掉，而是**只取图或只取文案，版式全部重排**：

| 旧页 | 取什么 | 新页 |
|---|---|---|
| P4 对比 | 取两张小图 | 两图放大 + 色温标注 + 暖冷对照表 |
| P11 冰晶 | 取产品照 | 全幅图 + 标题 + 香调 + 四条参数 |
| P8 灵感溯源 | 取文案 | 大字 + 中英双语 + 抠瓶 + 三条来源 |
| 原封面 | 整张装框 | 附在最后，标明"上一版" |

**规则：旧页面的图和字可以留，旧页面的版式（白底、价格、打勾）一律不留。**

## 六、11 页结构

```

10 自述         大字 + 中英对照 + 模糊背景

```

## 七、这一轮踩的坑（都不在手表那套里）

**① 生成的素材瓶型不一致**
```
AI 重新生成的 6 张里，4 张是别的瓶 → 全部弃用
只有"不露完整瓶型"的微距（盖内侧、纸盒）可用
教训：换素材前先问"它会不会露出产品轮廓"
```

**② 标签贴图必须量尺寸**
```
贴了四次才准：
  0.30–0.70  偏右、露原标签
  自动检测    检测到整块，贴满瓶子（最严重）
  0.255–0.765 右边留灰边
  0.238–0.792 才盖住
方法：把瓶子放大画网格，一格一格量四边
```

**③ 卡片里放产品图，不能用 cover**
```
cover → 瓶盖被切
contain → 完整但带旧页面文字（¥398）
正解：直接用抠瓶（完整、无杂质）
```

**④ 浏览器缓存会让你以为"没改"**
```
改完文件、刷新页面，看到的还是旧图
原因：文件名没变，浏览器读缓存
解决：img src 加 ?v=修改时间
```

**⑤ 封底的瓶子会盖住统计数字**
```
没算坐标就设 900 高 → 顶部顶到 620，正好压住 590 起的数字行
规则：贴任何图之前，先算它在版面上的 y 区间，和文字区间比对
```
