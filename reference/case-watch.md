# 案例一：观时 GUĀNSHÍ（暗调腕表，17 页）

结构化记录：背景 → 决策 → 结果 → 结论。每条决策标注所用工具与依据。

---

## 一、背景

| 项 | 内容 |
|---|---|
| 性质 | 自命题概念项目，虚构品牌，无真实产品与实拍 |
| 用途 | 作品集 |
| 输出 | 17 页，1200×1600；连续长图 1200×25438 |
| 素材 | 图像模型生成 41 张（深色木质桌面、黑壳表、机芯分解、微距、户外场景） |
| 约束 | 无法获得同一支表的多角度素材；图像内文本不可用 |
| 前期状态 | 完成后 16 页各自成图，色温与光向不一致，整组无统一性 |

问题定义：素材来自多个生成批次，光向与色温不统一；若逐页调参，成本随页数线性上升。
目标是在有限素材下，使 17 页呈现为同一次拍摄的结果。

---

## 二、决策

### D1 采用低调基底，而非逐页调光

| 项 | 内容 |
|---|---|
| 决策 | 全组统一背景基色 `#0E0B08`，页面在此基底上叠加内容 |
| 依据 | 素材本身为深木与黑壳，降低明度后色偏被压制；暗部承载文本，可读性高 |
| 代价 | 文字只能置于暗部或负空间；亮部素材需重新裁切 |
| 工具 | Pillow（画布与合成）、numpy（渐变与噪声） |

### D2 固定五色与四档字号

| 项 | 内容 |
|---|---|
| 决策 | 前景 `#EFE3CE`、辅助 `#8A7358`、金 `#C08A4A`、线 `#2E2318`、基底 `#0E0B08`；字号 T1 72 / T2 26 / T3 16 / T4 12 |
| 依据 | 字号级超过四档即出现层级争夺；色板固定后不再逐页微调 |
| 工具 | Pillow（`ImageFont.truetype` + variation 取字重） |

### D3 以页面类型矩阵分配 17 页

| 页 | 类型 | 待回答问题 |
|---|---|---|
| 00 | 纯字体封面 | 项目性质 |
| 01 | HERO | 品牌气质 |
| 02 | FEATURE | 表径设定的取舍 |
| 03 | HERO | 首要记忆点 |
| 04 | GRID | 材料与工艺 |
| 05 | SPEC | 结构组成 |
| 06 | HERO | 动力储存 |
| 07 | SPEC | 三处尺寸 |
| 08 | FEATURE | 厚度的构成 |
| 09 | SPEC | 表面变体 |
| 10 | GRID | 使用场景 |
| 11 | FEATURE | 微距做工 |
| 12 | BRAND | 方法与边界 |
| 13 | HERO | 色温表现 |
| 14 | DOC | 字体与栅格 |
| 15 | MONO | 去色后的结构可读性 |
| 17 | DOC | 方法与后续项 |

依据：单页仅承担一个问题；类型交替保证翻页节奏（每 3 页换型）。
工具：表格见 `templates/矩阵-观时17页.csv`。

### D4 统一色彩取代逐页调参

| 项 | 内容 |
|---|---|
| 决策 | 全组套用同一组参数：黑位 0.03、高光 0.97、高光区加暖 `[1.06,1.01,0.90]`、暗部加冷 `[0.93,0.98,1.10]`、主光左上 +8%／右下 −6%、暗角 22%、锐化 48% |
| 依据 | 光向不一致由统一主光校正；色温差异由冷暖分离校正 |
| 工具 | `scripts/grade.py`（Pillow + numpy） |

### D5 透明层 + 连续背景合成（阶段 ⑥）

| 项 | 内容 |
|---|---|
| 决策 | 页面导出为 RGBA 透明 PNG；背景为覆盖全高的单张连续图（纵向渐变 + 四道柔光带 + 侧向明暗 + 噪声 + 0.6 px 模糊）；页间隙 20 px |
| 依据 | 逐页携带基色会在页间形成硬边；连续背景使整组同处一个光照环境 |
| 例外 | `08-feature` 与 `12-brand` 为整幅不透明页，合成时不裁切、不羽化 |
| 工具 | `alpha_pages.py`（画布改 RGBA）、`build_long.py`（合成与切回单页） |

### D6 文案结构与禁用词拦截

| 项 | 内容 |
|---|---|
| 决策 | 文案统一为「部位 + 动词 + 结果 + 依据」；形容词与大词由脚本拦截 |
| 依据 | 无依据的评价不可验证，读者无法据此判断取舍 |
| 工具 | `scripts/checkcopy.py` + `templates/forbidden-claims.txt`（21 条禁用项，五类） |

### D7 长图尺寸作为验收指标

| 项 | 内容 |
|---|---|
| 决策 | 以 `1200×25438` 与页数 17 作为硬指标；不一致即失败 |
| 依据 | 该尺寸由 17 页内容高度与 16 个 20 px 间隙唯一确定，可反推版式是否被改动 |
| 工具 | `build_long.py`（断言）、`scripts/reproduce.py`（与基准逐页比对） |

---

## 三、结果

| 指标 | 数值 |
|---|---|
| 页面数量 | 17 |
| 长图尺寸 | 1200×25438 |
| 各页高度 | 1133–1600 px（见 `examples/watch/reference/manifest.json`） |
| 复现精度 | 高度全部一致；平均像素差 0.00–3.76（容差 6/255） |
| 校验 | `checkcopy` 0 命中；`checkregister` 0 命中；`selftest` 15 项通过 |
| 复现命令 | `python scripts/reproduce.py --case watch` → PASS |

未达成项：产品多角度一致性（受图像模型限制，见 `SKILL.md` 第十二节）。

---

## 四、结论

**可迁移的条件**

1. 素材同属一类影调（本例为低调）；混用高调素材时，D1 与 D4 不适用。
2. 页数 8–20；低于 8 页时成套流程的开销高于收益。
3. 文本可置于暗部或负空间；若素材占满画面，需先做裁切或加渐变遮蔽。

**不可迁移的部分**

1. 多角度一致性：需要 3D 建模，排版阶段无法实现。
2. 图像内文本：模型生成的中英文字不可用，需去背重绘（见案例二 D5）。

**方法层结论**

统一性来自三处，且优先级高于单页排版技巧：色彩统一（D4）、连续背景（D5）、
固定的字号级与色板（D2）。单页精修在缺少这三项时，不产生整组一致性。
