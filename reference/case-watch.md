# 案例：观时 GUĀNSHÍ（17 页 + 1200×25684 长图）

> 这是一次完整交付的实录。看结构、看决策、也看没做到的部分。

---

## 一、项目条件

```
性质      自命题概念设计（虚构品牌，无客户、无真实产品）
品类      38mm 自动机械腕表
素材      AI 生成（即梦 Seedream 5.0 + MiniMax image-01），35 张用 25 张
硬件      i3-10110U + Intel UHD + 8G（无独显 → 3D 不现实）
周期      两天（含 8 个版本迭代）
```

---

## 二、最终结构（17 页）

```
00 作品集封面   HERO    MECHANICAL / WATCH / VISUAL SYSTEM（纯字体）
01 封面         HERO    把时间戴在不看的地方（倒影 + 光晕）
02 为什么38     FEATURE 38 vs 44 的取舍
03 主视觉       HERO    齿轮不说谎
04 皮与钢       GRID    上排 3 工艺 / 下排 3 结构
05 机芯五件事   SPEC    分解图 + 5 编号 + 4 数字
06 十一点       HERO    篝火（概念演绎）
07 三处尺寸     SPEC    38/10.8/20 引线 + 3 圆放大 + 图标流程
08 侧过身       FEATURE 10.8mm 一句话
09 五种表面     SPEC    色卡 + 组合规则（含"不可做"）
10 它在哪       GRID    四场景（上暖下冷）
11 放大看机芯   FEATURE 双放大圆 + 四组数据
12 封底         BRAND   方法与边界
13 夜里三种光   HERO    窗光 / 火光 / 冰光
14 字与格       DOC     五档字号 + 12 列栅格
15 去掉颜色     MONO    黑白实验（给眼睛换气）
17 设计思路     DOC     方法论页（放最后）
```

---

## 三、三个关键决策（可复用到别的品类）

**① 把参数翻译成主张**
```
原始参数  38mm 表径
主张      "男表惯例 40–44。压到 38，袖口不打架，一天下来忘了它还在。"
做法      先问"这个数字改变了用户哪一件事"，再写文案
```

**② 主动标注限制**
```
在 00 页与封底写"已知限制：AI 无法稳定产出同一支表的多角度"
在概念页标「概念演绎 · 非产品图」
效果      懂行的人反而更信你 —— 因为别人都假装没这回事
```

**③ 长图用连续背景，不用拼接**
```
页面透明 → 一张 1200×25684 背景（纵向渐变 + 4 道柔光带 + 侧向明暗）
→ 叠层 → 出长图 → 按页高切回单页
结果      翻页没有"硬切"，像一本画册
```

---

## 四、没做到的部分（写进交付说明）

```
产品多角度一致    做不到，需 3D 建模
真实产品与实拍    没有（自命题项目本身没有）
渲染质感          追不上 3D 渲染的作品（这是硬差距，不是排版的锅）
```

---

## 五、文件结构

```
定稿\YYYY-MM-DD_<项目名>-vN\
  00-cover.jpg … 17-doc.jpg     单页（从长图切回，背景连续）
  长图-全17页.jpg               1200 × 25684
  长图-网页版.jpg               760 宽（浏览器可渲染）
  index.html                    逐页 / 长图 两个视图
  manifest.json                 每页尺寸 + SHA-256
  交付说明.md                   结构 / 手段 / 边界 / 下一步
```

---

## 六、给下一个项目的三条建议

```
① 素材先行：先把 20–30 张图生成完，再动排版
   （边排边找素材 = 无限返工）
② 张数先定：8 页就 8 页，别做 12 页的野心 + 4 页的素材
③ 阶段 ⑥ 不能省：不做统一调色 + 连续背景，整套就是"一叠图"
```
