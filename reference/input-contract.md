# 输入契约（开工前必须齐）

> 缺一条就停在阶段 0，不许"边做边找"。这套流程 80% 的返工来自输入不全。

---

## 五样素材

| # | 素材 | 合格标准 | 不合格怎么办 |
|---|---|---|---|
| 1 | 产品图 | 白底或纯色底；产品完整入画；≥2000px；无他人品牌名/水印 | 先补图，不进入下一阶段 |
| 2 | 产品事实 | 尺寸/材质/规格/价格/适用人群，逐项可核 | 缺项留空，**不许编** |
| 3 | 色彩与材质方向 | 一句话 + 3–5 个 HEX | 用默认板，但在矩阵里标"临时" |
| 4 | 图位矩阵 | 张数 + 每页回答什么问题 + 类型（HERO/FEATURE/SPEC/GRID/BRAND） | agent 起草，用户确认后才算数 |
| 5 | 用途与尺寸 | 作品集 / 电商 / 社媒；画布尺寸 | 未说明 → 默认作品集 3:4（1200×1600） |

---

## 四条硬性拒收

```
✗ 产品图里含其他品牌名、logo、水印（AI 生成图常自带假品牌名！）
✗ 产品主体被裁切（任一边缺角）
✗ "编造型"卖点：试香次数、销量、认证、获奖
✗ 素材是竞品详情页截图（含价格、平台 UI）
```

**第 1 条是 AI 时代最常见的坑**：即梦 / MiniMax 生成的表盘、包装盒上会编出 `JANIKOB`、`SWISS MADE` 之类的假字。
处理：① 重新生成（提示词加 `no text, no letters, no brand name`）② 裁切掉 ③ 压一块暗色铭牌盖住。
**遮不住就换图，不许"反正看不出来"。**

## 素材清单模板

```
产品名：
行业：
产品图：<路径> × <张数>，底色 <白/纯色>
核心事实：尺寸 ｜ 材质 ｜ 规格 ｜ 价格 ｜ 人群
色彩方向：<一句话>  色值 <#xxxxxx, #xxxxxx, ...>
图位数量：<N>
用途与平台：<作品集 / 电商 / 社媒>  尺寸 <1200×1600>
```

---

## 阶段 0 退出条件

```
□ 产品图 ≥1 张，通过四条拒收检查
□ 核心事实已填，空项标注"未提供"
□ 色彩方向已定（临时也算，但必须标明）
□ 用途与尺寸已定
□ 图位矩阵已确认（阶段 1 产出）
```
