# 已知问题库（均为实际发生案例）

> 按"发生频率"排序。开工前读一遍，交付前对照一遍。

---

## 一、AI 生成图

**1. 表盘/包装上编假品牌名**
```
症状  JANIKOB SHILAOGRON / SWISS MADE / 假日历窗
原因  模型倾向于"补全"表盘文字
处理  提示词加 "no text, no letters, no numbers, no brand name"
      仍出现 → 裁切 / 压暗色铭牌 / 换图
纪律  禁止"看不出来"
```

**2. 多角度不一致**
```
症状  正视图、侧视图、场景图里是三块不同的表
原因  AI 每次重新"想象"，没有模型概念
处理  概念页标注「概念演绎 · 非产品图」；产品页只用同一批图
根治  3D 建模（Blender / 外包），这是唯一的解
```

**3. 表型跑偏**
```
症状  要求单表冠，生成出两个计时按钮；要求圆壳，生成方壳
处理  提示词加 "single crown, no chronograph pushers, round case"
      两次仍不行 → 换角度（拍侧面/局部，避开表盘）
```

## 二、去背与裁切

**4. 纯白背景去背抠不干净**
```
症状  阈值 250 留下米白边；漫水填充漏进表盘吃掉白色零件
原因  "白底"是米白 + 有渐变，不是纯白
处理  放弃抠图。改用：① 图片放进深色"图版"（contain + 描边）
      ② 生成时就要求深色背景
判定  白色底图直接置于深色背景时，边界可被识别为拼贴
```

**5. cover 硬裁把产品切断**
```
症状  宽幅格里放整表，左右被切掉一半
处理  含"完整产品"的格一律用 contain 补底色
      只有材质/微距可以用 cover
```

## 三、版式设计

**6. 文字压产品**
```
症状  副标压在表带、表壳上，读起来费劲
处理  先找图的暗区，再放字；暗区不够 → 加方向渐变
      副标跨到产品边缘 → 缩窄宽度或提前换行
```

**7. 字号级过多**
```
症状  一页里 40/26/21/19/52/15 六档混用，看起来乱
处理  收到四档：72 / 26 / 16 / 12
```

**8. 同一张图被裁多次放进同一页**
```
症状  GRID 三格取自同一张图的不同局部，重复可被识别
处理  每格必须来自不同源图
```

**9. 页面间素材重复**
```
症状  第 10 页和第 13 页用了同一张"结霜的窗"
处理  建一张"素材 → 页面"对照表，重复就换（备用图里挑）
```

**10. 底部大片空白**
```
症状  内容结束在 70% 高度，下面全是黑
处理  ① 补一个数据行/说明块 ② 或长图合成时自动裁掉
      自动裁剪：从底部往上，遇到"暗且平"（mean<26 且 std<6）就裁
```

## 四、合成与长图

**11. 浏览器渲染不了超长图**
```
症状  长图 1200×27000 在浏览器里一片空白
原因  Chrome 单图高度上限约 16384 px
处理  网页看板用 760–800 宽（高度 ≈ 14000–16000）
      交付原图另存 1200 宽，附分段预览
```

**12. 页面各带一块黑底导致长图"硬切"**
```
症状  每页之间有明显的矩形边界
处理  页面导出为透明 PNG（RGBA 画布），叠在一张连续背景上
      不透明页（外部 jpg）上下 60 px 羽化融入
```

**13. 图片上缘硬边**
```
症状  产品图贴在版面上，上沿一条直线
处理  用 paste(band, mask) 画 300–420 px 的黑→透明过渡
      注意：在透明画布上直接贴带 alpha 的色块会变成一块褐斑，要放在图之后
```

## 五、工具与环境

**14. DSH / IDE 窗口抢焦点**
```
症状  脚本 SetForegroundWindow 到浏览器后，一跑命令焦点又跳回 IDE
处理  先把 IDE 窗口 SetWindowPos 到 (-3000, 0)，操作完再还原
```

**15. 网页输入框打不进字**
```
症状  SendInput 逐字符发送，输入框始终为空
原因  富文本容器 / 定制浏览器拦截
处理  放弃自动输入。用剪贴板 + 手动粘贴，或让用户点
      能自动化的：设剪贴板、Ctrl+L、Ctrl+V、回车、截图
```

**16. 站酷等站点 403 / 懒加载**
```
症状  抓图返回 403；或页面截图是白块
处理  403 → 用他自己的浏览器（已登录）
      白块 → 慢滚 + 每屏等 3 秒再截；每次滚动 3 格，不得一次性滚到底
```

## 六、流程

**17. 没有外部反馈连改十几版**
```
症状  同一页修改超过 6 次，评审仍判定不通过
原因  没有可衡量的标准，改的是情绪不是问题
处理  ① 定"能发出去"的最低标准 ② 每次改动必须对应一句具体缺陷
      ③ 三版不动就停下，让用户指认"哪一页哪一处和哪张参照比"
```

**18. 中途中加页**
```
症状  "再加一页吧"，最后 12 页变 19 页，节奏全乱
处理  页数在阶段 ② 确定；如需增加，重新编排整份，不得插入既有页序
```
