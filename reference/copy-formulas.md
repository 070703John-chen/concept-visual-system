# 文案句式库（部位 + 动词 + 结果）

> 不写形容词。每条文案都要能被验证或被指认。

---

## 公式

```
[部位/功能] + [动词] + [对用户的结果] + [依据/场景]
```

---

## 好的写法（可抄）

**产品类**
```
防滑按钮 · 保护 · 湿手时的误触危险 · 依据：湿手场景
10.8 毫米 · 滑进袖口 · 不顶袖口那一下 · 依据：衬衫袖口
38 毫米 · 压小两档 · 戴一天忘了它还在 · 依据：男表惯例 40–44
蓝宝石单面防眩 · 镀膜朝外 · 内侧不镀 · 依据：单面镀膜工艺
马鞍针 · 两根线交叉穿 · 断一处其余仍锁住 · 依据：缝法对比
```

**信息类**
```
12 行参数 · 一项可查 · 不写"高性能"
5 种表面 · 换电镀不换壳型 · 一条线能扩五支
0 个计时按钮 · 少一个开孔 · 少一处漏水
```

**限制类（这条最加分）**
```
米白盘 × 夜光 · 不可做 · 底色太浅压不住对比
AI 无法稳定产出同一支表 · 概念页标注「概念演绎」
参数为方案设定值 · 非实测 · 真实产品须以出厂检测为准
```

---

## 禁用

```
✗ 高级 / 优雅 / 轻奢 / 质感拉满 / 匠心力作
✗ 引领 / 赋能 / 重新定义 / 颠覆
✗ 秒杀同级 / 闭眼入 / 必买
✗ 销量 XXX / 好评率 99% / 认证 / 获奖（无凭证）
✗ "198 次试香""365 天打磨"（编的）
✗ 感叹号、emoji、口号式短句
```

---

## 标题的两种写法

**A. 主张型（2–5 字，压得住）**
```
齿轮不说谎
皮与钢
侧过身
十一点
```

**B. 数字型（大号数字 + 一句解释）**
```
38  → 袖口不打架
10.8 → 滑得进袖口
21600 → 次/小时
```

---

## 英文的使用规则

```
只做装饰：标签、英文色名、副标一句
sentence case（只句首大写），不做全大写长句（封面巨型英文除外）
字距 +8%，用于品牌行与标签
英文不承担关键信息（读者可能不看）
```

---

## 校验三问

```
① 这句话能不能被一张图或一个数字证明？
② 把品牌名换成别人，还成立吗？（成立＝太泛）
③ 有没有形容词在没有依据的情况下撑门面？
```
