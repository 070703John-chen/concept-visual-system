# 像素级版式规格（1200×1600 画布）

> 所有数字都是实测过的，直接抄。

---

## 画布与安全边距

```
画布        1200 × 1600（3:4）
外安全边距  72 px（上下左右）
内边框      内缩 34 px 一圈细线（深色页 #4A3722，1px）
页脚区      底部 110 px（放页点 + "下一页 xx"）
有效内容区  1200 × (1600 - 72*2)
```

---

## 字号四档

| 档 | 用途 | 字号 | 字重 |
|---|---|---|---|
| T1 | 主标题 / 巨型英文 | 64–104 | Bold |
| T2 | 副标 / 数字 | 24–32（数字可到 46） | Medium |
| T3 | 正文 | 16–18 | Regular |
| T4 | 注 / 标签 / 页码 | 11–13 | Regular |

```
文字块最大宽度   480 px（1200 画布）
一句话最多行数   3 行
中英混排         英文只做装饰（T4 大写 + 字距 +8%），不承担信息
```

---

## 色板（暗色系示例）

```
底       #0E0B08   （近黑，留 0.5% 暖）
面板     #171310
分隔线   #2E2318 / #4A3722
正文     #EFE3CE
次要     #8A7358
强调     #C08A4A（铜金）
警示     #C06A4A
```

**对比度**：正文 ≥ 4.5:1，装饰性大字 ≥ 3:1。低于 3:1 时必须更换色值，不得以「观感尚可」替代测量。

## 图块尺寸（常用）

```
满幅       1200 × 任意
左图右文   520 × 690（图） + 右侧 560 宽文字栏
三格       352 × 250（间距 12）
两格       522 × 300（间距 12）
宽幅       1056 × 420（居中，contain）
圆形放大   直径 128 / 150 / 196（按层级）
```

## 双列栅格（参数页）

```
左栏   72 → 592（宽 520）
右栏   612 → 1128（宽 516）
列中缝 20
12 行参数时行高 66–70
```

---

## 文字位置铁律

```
① 文字只放在：图内暗区 / 图外纯色区 / 压暗渐变上
② 绝不压在产品主体（表盘、瓶身、机身）上
③ 图内放文字前，先画方向渐变：
   左侧暗 → 从左往右 (1-t)^1.2 递减
   底部暗 → 从下往上递减
④ 副标若跨到产品边缘，缩窄宽度或提前换行
```

---

## 长图相关

```
页间距       20 px
单页高度     由内容决定（透明裁边后 1100–1600 不等）
长图宽度     1200
浏览器上限   单张图高度 > 16384 px 会渲染失败
             → 网页看板用 760–800 宽（高度 ≈ 14000–16000）
             → 交付原图给 1200 宽 + 分段预览
```
