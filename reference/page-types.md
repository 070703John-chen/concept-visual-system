# 五种页面类型 + 图像位矩阵

> 一页只用一种类型。混用是"看起来乱"的头号原因。

---

## HERO

```
结构  满幅图（cover） + 2–3 行大字 + 1 行副标
文字  压在图内的暗区（不是压在产品上）
字号  T1 主标（64–104） + T3 副标
用在哪 封面、主视觉、氛围页
```

**关键**：先确认图的"暗区"在哪，再把文字放进去。暗区不够 → 加一层方向性渐变（左/右/上/下），不得整体降低明度。

---

## FEATURE

```
结构  一张图 + 一句公式文案 + 1–3 格数字
文字  在图外或图内单侧
字号  T2 主句 + T3 说明 + T4 注
用在哪 单点证明（厚度、工艺、取舍、材质）
```

**关键**：一句只讲一件事。想讲两件 → 拆成两页。

---

## SPEC

```
结构  左图右表 / 全表 / 图 + 参数块
内容  8–14 行参数，或 4–6 个数字
字号  T3 行值 + T4 行名 + 大号数字（34–46）
用在哪 参数、分解图、变体色卡
```

**关键**：参数行的**顺序本身就是逻辑**（从外到内：壳→冠→圈→盘→针→镜→盖→带→扣→防水）。

---

## GRID

```
结构  2×2 或 2×3 等分格
每格  一张图 + 3–5 字标签
字号  T4 标签
用在哪 材质拼贴、场景拼贴、结构索引
```

**关键**：
- 每格须来自**不同素材**（同一张图多次裁切可被识别）
- 含"整表"的格用 `contain` 补基色，不得使用 `cover` 强制裁切

---

## BRAND

```
结构  品牌名 + 一句主张 + 方法与边界（限制写在明处）
字号  T2 主张 + T3/T4 说明
用在哪 封底
```

**关键**：写"已知限制"比写"谢谢观看"专业十倍。

---

## 图像位矩阵模板

```
| # | 页名 | 类型 | 回答什么问题 | 素材来源 | 有人吗 |
|---|------|------|--------------|----------|--------|
| 01 | 作品集封面 | HERO | 这是什么项目 | 纯字体 | 无 |
| 02 | 封面 | HERO | 品牌气质 | 主视觉 | 无 |
| 03 | 为什么是 38 | FEATURE | 为什么不做 44 | 侧面 | 无 |
| 04 | 主视觉 | HERO | 首要记忆点 | 主视觉 + 倒影 | 无 |
| 05 | 材质 | GRID | 摸起来怎么样 | 6 张近看 | 无 |
| 06 | 结构 | SPEC | 由什么组成 | 分解图 | 无 |
| 07 | 参数 | SPEC | 规格可查吗 | 白底正面 | 无 |
| 08 | 侧面 | FEATURE | 薄在哪 | 侧面 | 无 |
| 09 | 变体 | SPEC | 有几种 | 色卡 | 无 |
| 10 | 场景 | GRID | 什么场合用 | 4 张场景 | 手 |
| 11 | 细节 | FEATURE | 做工经得起看吗 | 微距 | 无 |
| 12 | 包装 | GRID | 开箱是什么样 | 礼盒 | 无 |
| 13 | 封底 | BRAND | 方法与边界 | 纯文字 | 无 |
```

**矩阵确定后页数即锁定。** 中途加页视为范围变更。
