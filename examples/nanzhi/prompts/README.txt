# 亮调项目的关键：不许压暗；素材必须高调，信息全在亮部

# 01 主图（白底，用于抠瓶）
身份锁：同一支方肩玻璃香水瓶，金色方形盖，米色标签，50ml
场景锁：纯白无缝背景（RGB > 238），柔和顶光无影，正面平视
创意锁：抠出来做"同一支瓶"的母版

# 02 场景：窗边木桌

场景锁：米白墙面，左侧自然窗光，木桌纹理清晰，背景留白可压字
创意锁：日常场景，不是广告棚

# 03 细节：玻璃与液体的折射

创意锁：证明材质

# 04 金属盖内侧

# 05 纸盒平面

场景锁：纯米色背景，顶光，微投影
