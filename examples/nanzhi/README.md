# 示例二：南枝 NÁNZHÍ（亮调香水 · 11 页）

**与手表示例互补**：手表是暗调、强结构；南枝是亮调、信息密集，而且是从一套旧电商页面改造来的。

```bash
cd examples/nanzhi
python scripts/preflight.py --out-dir ./out

python scripts/build_pages.py     # 第一段：9 页（渐变 + 抠瓶 + 信息排版）
python scripts/build_final.py     # 第二段：11 页（旧图新装 + 冷调款 + 附原版封面）
```

产物：`out/`（9 页，中间产物）+ `out/final/`（11 页，定稿）。

---

## 目录

```
config.json          色板（亮调）/ 字号 / 画布 / 路径 / 文案清单
assets/              41 张（原片 + 新素材 + 弃用素材都在，脚本按文件名取）
scripts/
  cfg.py             读 config，给出 ASSETS / OUT
  kit.py             字体与配色
  build_pages.py     9 页：封面 / 香调分析 / 材料 / 信息 / 香型卡 / 两种光 /
                     冷调 002 / 冰晶 / 自述 / 封底
  build_final.py     11 页：再加 灵感溯源、附原版封面（从旧页面取图取文重排）
```

---

## 这条流程里最关键的三件事

**① 纯白背景素材抠瓶 → 从此"同一支瓶"可以放在任意背景**
```
assets/NZ-主图-白底-1200.jpg → 阈值 238 漫水 → 边缘羽化 1.2px → 521×967
```

**② 亮调不能用暗调参数压**
```
试过：压暗一档 → 白衬衫变脏灰；压暗+冷处理 → 廉价感更重
改判：保留亮调，靠"信息密度 + 同一套背景"统一
```

**③ 旧页面只取图/取文，不取版式**
```
P4 对比   → 两张图放大 + 色温标注 + 对照表
P11 冰晶  → 全幅图 + 参数条
P8 灵感   → 文案重排 + 抠瓶 + 三条来源
原封面    → 装框，标明"上一版"
```

---

## 改东西改哪里

| 想改 | 改哪 |
|---|---|
| 主调（亮/暗） | `config.json` → `palette`，同时看 `build_pages.py` 里的 `grad()` 起止色 |
| 文案 | 对应 `build_*.py` 的 `d.text(...)`（同表：尚未接线） |
| 页数 | `config.json` → `pages`（仅用于核对，实际由脚本决定） |

---

## 已知限制

```
① 文案在脚本字面量里（路线 1.5 的范围）
② 002 冷调瓶是"同一支瓶换色 + 重绘标签"，不是第二支真实瓶
   标签框用网格量出来的：x 0.238–0.792 / y 0.370–0.742
③ 12-附原版封面 只用于单页展示，长图合成时排除
   （长图里它是第二个封面，会让结尾显得没收住）
```

---

## 复现核对表

```
build_pages.py   → out/ 下 9 页
build_final.py   → out/final/ 下 12 页（11 页定稿 + 1 张附原版封面）
```

若 `out/` 里缺原片，说明 `assets/` 没复制全 —— 脚本会报"找不到 NZ-P1-场景.jpg"这类错，
**不会静默出一张空白页**。
