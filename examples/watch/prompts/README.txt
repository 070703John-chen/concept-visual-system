# 观时 GUĀNSHÍ · 生图提示词（一行一条，# 开头是注释）
# 三段式：身份锁（同一支表）+ 场景锁（同一套光）+ 创意锁（这张要证明什么）
# 负向固定加在 gen_images.py 里：no text, no letters, no numbers, no brand name, no logo
# —— 正面表盘必然被编出假品牌名与假日历窗，这是硬限制

# 01 主视觉：齿轮镂空 + 侧光，用于封面与表径页
身份锁：同一支 38mm 圆形自动机械腕表，黑色 PVD 精钢表壳，镂空盘面可见齿轮与摆轮，黑色牛皮表带
场景锁：深色胡桃木桌面，左上 45° 暖色侧光，背景压到近黑，浅景深
创意锁：证明"盘面被打开过"，齿轮是第一眼记住的东西

# 02 机芯分解：悬浮零件阵列
身份锁：同一支表的机芯零件（主夹板、齿轮系、擒纵、摆轮、发条盒）悬浮分层排列
场景锁：纯黑无缝背景，顶光 + 微弱轮廓光，无投影
创意锁：让"结构可查"这件事可视化

# 03 侧面厚度：10.8mm 的来源
身份锁：同一支表的正侧面视图，表壳侧面轮廓完整，表冠可见
场景锁：深棕背景，单侧硬光压出壳壁高光，45° 俯视
创意锁：让"薄"可被量（配合尺寸页引线）

# 04 微距：做工细节
身份锁：同一支表的表耳/表带缝线/表冠滚花微距
场景锁：极浅景深，单一光源，背景完全虚化
创意锁：经得起放大看

# 05 手持：真实尺度
身份锁：同一支表戴在手腕上（手腕周长 15–18cm 参考）
场景锁：室内暖光，手背自然放置，背景为深色木质桌面
创意锁：给出真实尺度参照

# 06 场景：帐篷 / 雪地（概念演绎，非产品图）
身份锁：同一支表出现在户外场景中，不要特写盘面
场景锁：帐篷内暖灯 / 雪地冷光，二者色温必须明显对立（2700–3200K vs 5600K）
创意锁：说明"换成什么光，它像什么"

# 07 背景板：木屋暖光 / 灯笼暖光（只出背景，不出产品）
身份锁：无产品
场景锁：木屋室内墙面 + 灯笼暖光，虚焦，可作文字底板
创意锁：给文字一个可压的暗区

# 08 白底：用于抠图
身份锁：同一支表，正面
场景锁：纯白无缝背景（RGB > 238），均匀无影，正面平视
创意锁：抠出来当"标准件"复用
