# 踩坑入库模板

> 新坑照这个格式加进 `reference/pitfalls.md`。四段缺一不可。
> 判断"值不值得入库"：**同类活里会不会再遇到**。只遇到一次且不再发生的，不写。

---

## 复制这段

```
## 编号（递增）· 一句话标题

症状
  看到什么现象（要具体：错在哪、什么颜色、什么尺寸）

原因
  为什么会这样（技术原因，不是"我不小心"）

处理
  怎么修（给命令/参数/代码片段）

验证
  修好后怎么确认（跑什么、看什么）

代价
  这个修法有什么副作用（没有就写"无"）
```

---

## 已入库示例（照这个粒度）

```
## 17 · 生成图的标签贴歪

症状
  冷调版瓶身重绘标签后，贴图偏右、右边露出原标签的一条灰边

原因
  标签区域是估的（0.30–0.70），不是量的

处理
  把瓶子放大十倍画 10% 网格，量出实际范围 0.238–0.792 / y 0.370–0.742，
  按这个矩形重贴

验证
  放大到 200% 看瓶身边缘，无灰边、无错位

代价
  每换一个瓶型都要重量一次（约 5 分钟）
```

---

## 反例：不要这样写

```
✗ "注意标签位置" —— 没有症状、没有参数，下次仍然会错
✗ "AI 生成的不准" —— 这是抱怨，不是处理
✗ "用 Photoshop 修一下" —— 不可复现
```
